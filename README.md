# ARGON OPTICS // Ar-18 전술 야간 투시경 (Night Vision Web App)

모바일 및 PC 브라우저에서 외부 라이브러리 설치나 빌드 과정 없이 즉시 실행 가능한 고성능 광학 야간 투시(Tactical Night Vision) PWA 웹 애플리케이션입니다.

- **GitHub 저장소**: [https://github.com/kiuza1004/NightVision_anti](https://github.com/kiuza1004/NightVision_anti)
- **온라인 실행 (GitHub Pages)**: [https://kiuza1004.github.io/NightVision_anti/](https://kiuza1004.github.io/NightVision_anti/)

## 🌟 주요 핵심 기술 및 기능

### 1. 진짜 저조도 야간 투시 엔진 (Real Low-Light Night Vision ISP)
- **하드웨어 수광 부스트 (EV+)**: 카메라 센서 노출 보정(`exposureCompensation`)을 최대치로 자동 인가하여 센서 물리 수광량 극대화
- **비선형 암부 감마 리프트 LUT**:
  - `1단 표준 (γ=0.48)`: 암부 약 2.5배 증폭
  - `2단 강력 (γ=0.34)`: 칠흑 같은 어둠 속 암부를 약 4.5배 부스트
  - `3단 극강 (γ=0.24)`: 맨눈으로 식별 불가한 극저조도를 최대 8배까지 선명하게 복원
  - **백화(White Blowout) 및 깜빡임 원천 차단**: 0~255 전 구간 보존 및 Reinhard 소프트-니 압축 결합
- **모션 적응형 시간축 노이즈 적분 (Temporal DNR)**:
  - `Float32Array` 기반 프레임 누적 버퍼 운용
  - 정지 배경의 센서 열잡음은 강하게 평활하고, 움직이는 동체는 잔상 없이 즉각 반응

### 2. 6종 전술 광학 스펙트럼 필터
1. **트루컬러 야간 (TrueColor NV)**: 원본 색상 왜곡 없이 어두운 곳만 대낮처럼 복원
2. **P43 그린 (Emerald Phosphor)**: 군용 전술 야간투시경 특유의 녹색 형광체 톤
3. **Ar-18 시안 (Cyan High-Contrast)**: 차가운 아이스 시안 계열의 고대비 투시
4. **윤곽 강조 (Mono High-Pass)**: 어둠 속 물체 윤곽선 식별 극대화 모노크롬
5. **열화상 LUT (Thermal Ironbow)**: 256단계 사전 계산 컬러 테이블 기반 의사 열화상 스펙트럼
6. **주간/자동 (Standard Auto)**: 평소에는 주간 모드로 동작하다가 조도 저하 시 자동 ISP 개입

### 3. 3대 전술 운용 모드
- **01 실시간 야간투시 (Live NV)**:
  - 실시간 암부 증폭, 32-bin 휘도 히스토그램, 조준선(HUD), 원본 비교(HOLD)
  - **터치 4X/8X 정밀 돋보기 (Loupe)**: 화면 터치 지점을 최대 8배율로 선명하게 확대
- **02 야간 동체 레이더 (Night Radar)**:
  - 칠흑 속 미세 모션 감지, 배경 흔들림 보정, 표적 락온 브래킷, 소나 경보음 및 햅틱 진동 알림
- **03 초저조도 장노출 합성 (Astro Long Exposure)**:
  - `1.5s` / `3.0s` / `5.0s` 다중 프레임 실시간 빛 누적 합성
  - `HDR 합성` (톤매핑), `MAX 빛모음` (미세 광원/별빛 누적), `AVG 정밀` (노이즈 완전 제거)

### 4. 편의 기능 & 시뮬레이션 데모
- **온디바이스 100% 처리**: 서버 통신 없이 기기 내부에서 실시간 60fps 연산 (개인정보 보호, 비용 0원)
- **암실 시뮬레이션 데모**: PC나 웹캠이 없는 환경에서도 암실 시뮬레이션으로 성능 실증 가능
- **하드웨어 토치 & 화면 백라이트 링**: 후면 플래시가 없거나 전면 카메라일 때 화면 고휘도 조명 링 가동
- **고해상도 캡처**: 광학 메타데이터 워터마크가 포함된 고화질 스냅샷 즉시 저장

## 🚀 로컬 실행 방법

Python 3만 설치되어 있다면 별도의 패키지 설치 없이 즉시 실행할 수 있습니다.

### Windows:
`start_server.bat` 더블 클릭

### CLI (터미널):
```bash
python server.py
```
브라우저에서 `http://localhost:8080`에 접속합니다.

---

## 📱 스마트폰 모바일 접속 팁
- PC와 스마트폰을 같은 Wi-Fi에 연결한 후 터미널에 표시된 `http://[PC_IP]:8080` 주소로 스마트폰에서 접속합니다.
- 모바일 크롬 브라우저에서 카메라 권한 허용을 위해 `chrome://flags` -> `unsafely-treat-insecure-origin-as-secure` 항목에 접속 IP를 등록하면 스마트폰 브라우저에서도 실제 카메라로 원활히 실행됩니다.
